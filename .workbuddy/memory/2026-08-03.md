## 🔧 CI 编译失败 + 修复（2026-08-03 晚，push 后）
- CI（build.yml）报错：`DYYY.xm:3112: error: %init for an undefined %group DYYYCommentExactTimeGroup`。
- **根因（拆分引入的 Logos 顺序坑）**：我把 6 个 `#include` 片段放在壳文件 `DYYY.xm` **末尾（%ctor 之后）**。片段里含全部 `%group` 定义，展开后跑到壳 `%ctor` 里 `%init(group)` 的**后面**，Logos 要求 `%group` 必须先于 `%init` 定义 → 报 undefined。
- 之前「逐行等价」校验只查了内容集合、漏了 Logos 指令的**语义顺序**，所以没提前发现。
- **修复**：把 6 行 `#include` 从文件末尾移到 `%ctor` **之前**（纯行挪位，内容零改动）。提交 `1806757`「fix: move fragment #includes before %ctor...」，SSH 推送成功 `e544f01..1806757 main -> main`，CI 已重新触发。
- **校验脚本**：C:/Users/hxy24/WorkBuddy/verify_init_order.py —— 模拟 C 预处理器展开 `#include`，逐条确认每个 `%init(X)` 对应的 `%group X`/`%subclass X` 定义都在其之前；并正确处理 Logos 类替换语法 `%init(ClassName = expr)`（这种不需要 %group，应跳过）。修复后输出「ALL %init targets are defined BEFORE their init. OK.」
- **可复用教训**：Logos 拆分用 `#include` 拼接时，**必须保证所有 `%group`/`%subclass` 定义所在的片段，`#include` 位置早于执行 `%init` 的 `%ctor`**（通常把所有 include 放在 `%ctor` 之前最稳）。同时「按下等同」≠「Logos 语义等价」，含 Logos 指令的拆分要专门校验指令顺序。

## 🔧 CI 仍失败 → 真因是主文件扩展名（2026-08-03 深夜，推翻上一条诊断）
- 用户再次贴 CI 同错：`DYYY.xm:3119: error: %init for an undefined %group DYYYCommentExactTimeGroup`（行号已变 3119，说明 1806757 的 include 顺序修复**已生效**——includes 已在 %ctor 之前——但**错误依旧**）。故「include 顺序」并非根因。
- **真因**：theos 的 hook-splitting 要求**主文件必须是 `.xmi` 扩展名**。Logos 预处理器**只有对 `.xmi` 主文件才会把 `#include` 的片段合并进同一翻译单元**；主文件若是 `.xm`，Logos 根本不内联片段 → 片段里的 `%group` 对主文件 `%ctor` 的 `%init` 完全不可见 → undefined %group。这正是症状：group 在片段里、%init 在壳里，壳是 `.xm` 所以片段没被合并。
- **所以 1806757 无效**：它只挪了 include 行位置，主文件仍是 `.xm`，Logos 压根没合并 → groups 永远看不到。`.xmi` 才是触发合并的开关。
- **修复**：`git mv DYYY.xm DYYY.xmi`；`Makefile` 的 `DYYY_FILES` 首文件 `DYYY.xm → DYYY.xmi`（片段 .xm 仍只被 #include、不入 DYYY_FILES）；同步更新 6 片段头注释与 AGENTS.md 的 `DYYY.xm` 引用 → `DYYY.xmi`。提交 `e49a6f9`，SSH 推 `main`，CI 重触发。
- **官方依据**：theos.dev/docs/logos-hook-splitting ——"the main file has to be renamed to an .xmi file. Then, other .xm files can be included... The Logos pre-processor will add those files to the main file before processing it."
- **铁律（可复用）**：用 `#include` 拆分 Logos 时，**主文件必须 `.xmi`**，被拆片段保持 `.xm` 且**只**出现在 `#include` 里（绝不能同时列进 `XXX_FILES`），否则片段不被合并或重复编译。
